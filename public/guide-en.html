Get started in 4 steps

Every tool works the same way. Learn it once and you can use them all.

  1. Choose a toolTap an icon, for example “Merge PDF” or “Compress PDF”.
  2. Add your fileDrag a file in, or tap the dashed blue box and pick a file from your device.
  3. Tap “Start processing”If the tool has options, such as the compression level, set them first.
  4. Get your fileIt downloads by itself. If it does not, tap the blue “Save file” button.

🔒 Your files go nowhere

Everything runs inside your own browser, so there is no upload to wait for, and it suits sensitive papers such as ID card copies. When processing finishes, the “Processing receipt” box shows how many requests sent data out of your device. The correct number is 0.

Want to check it yourself? Turn on airplane mode and use a tool. See how on the privacy page (Thai).

How to use each tool

Every tool starts the same way (choose it, then add your file). Below are the details that are specific to each one.

📷 Images to PDF

Combine several pictures into one PDF. Good for photos of documents or receipts.

  • Accepts: several images (JPG, PNG, WebP)
  • Gives you: EasyConvert_Images.pdf
  1. Choose “Images to PDF”
  2. Add all the pictures, either together or one at a time
  3. Check the list under the box. The first picture becomes page 1
  4. Tap “Start processing”

💡 If the order is wrong, tap × on the picture to remove it and add it again. Newly added pictures always go to the end of the list.

🖼️ PDF to images

Turn each page of a PDF into a JPG picture.

  • Accepts: one PDF at a time
  • Gives you: JPG (several pages come as a ZIP)
  1. Choose “PDF to images”
  2. Add the PDF
  3. Tap “Start processing” and wait until every page is done
  4. A one-page PDF gives a single picture. A longer one gives filename_pages.zip containing Page_1.jpg, Page_2.jpg and so on

💡 On iPhone and iPad, tap the ZIP in the Files app to unzip it.

🧩 Merge PDF

Join several PDFs into one file.

  • Accepts: several PDFs
  • Gives you: EasyConvert_Merged.pdf
  1. Choose “Merge PDF”
  2. Add all the PDFs to join
  3. Check the order in the list. The top file becomes the first pages
  4. Tap “Start processing”

💡 If the order is not what you want, tap × to remove a file and add it again in the right order. Files added later go to the end of the list.

✂️ Extract pages

Keep only the pages you need and get a new PDF.

  • Accepts: one PDF at a time
  • Gives you: filename_pages.pdf
  1. Choose “Extract pages” and add the file
  2. Type the pages to keep in the “Pages to keep” box
  3. Tap “Start processing”

💡 How to type it: 2-4 means pages 2 to 4 · 5 means page 5 only · 1-3, 5, 7-10 means several ranges separated by commas.

⚠️ If a page number is larger than the page count, the tool shows “Invalid page range, or it exceeds the page count”. Check the numbers and try again.

🗜️ Compress PDF

Make a PDF smaller for email, chat or upload.

  • Accepts: one PDF at a time
  • Gives you: filename_compressed.pdf
  1. Choose “Compress PDF” and add the file
  2. Pick a compression level (see the table below)
  3. Tap “Start processing”
LevelWhat you get
LightKeeps the text, so you can still select and search it. The file gets a little smaller
MediumPages become pictures. Good quality, clearly smaller file
StrongPages become pictures. Smallest file, images may look softer

💡 Try “Light” first. Go stronger only if the file is still too big.

⚠️ Medium and Strong make the text impossible to select or search. If compressing does not make the file smaller, nothing is downloaded and the tool suggests a stronger level.

📏 Shrink to size New

Set the largest size you can accept, for example 200 KB, and the tool lowers the quality step by step until it fits. Good for job sites or portals that limit file size.

  • Accepts: several images or PDFs
  • Gives you: _small.jpg / _small.pdf (several files come as a ZIP)
  1. Choose “Shrink to size” and add your files
  2. Type the maximum size and pick KB or MB
  3. Tap “Start processing”
  4. The message afterwards shows the old and new size

💡 A file that is already under your limit is returned unchanged, so quality is never lowered for nothing.

⚠️ A shrunk PDF becomes pictures, so its text cannot be selected. If the smallest possible result is still over your limit, the tool tells you the smallest size it could reach and suggests a larger target.

🪪 Copy watermark New

Stamp a line of text across an ID card copy or other document, saying what it is for, so nobody can reuse it for something else.

  • Accepts: several images or PDFs
  • Gives you: _watermark.jpg / .png / .pdf (several files come as a ZIP)
  1. Choose “Copy watermark” and add your files
  2. Type the watermark text, or tap a ready-made text under the box and edit it
  3. Adjust the “Strength” slider so it is readable but does not cover important details
  4. Tap “Start processing”

💡 A good watermark says three things: who receives it, what it is for, and that it must not be used for anything else. For example “Copy for ABC Co. job application only. Not for any other use.”

⚠️ The result is a picture, so the watermark cannot be removed, and a PDF’s text becomes impossible to select. Keep your original file as well.

✍️ Sign PDF New

Place a signature, name or date on a PDF. The existing text stays selectable and searchable.

  • Accepts: one PDF at a time
  • Gives you: filename_signed.pdf
  1. Choose “Sign PDF” and add the PDF. The signing steps appear under the box
  2. Step 1, create the signature. Pick a tab: Draw with a finger or mouse · Type name in a handwriting font · Image from a photo or scan of your signature · Text / date such as “Certified true copy”. Pick blue or black ink, then tap “Add to this page”
  3. Step 2, place it. Drag the signature to the right spot, resize from the bottom-right corner, tap × to delete it, and change page with the “Previous page” and “Next page” buttons
  4. Tap “Start processing” to save. Your original file is not changed. You get a new file

💡 Tick “Remember my signature on this device only” so you do not have to redraw it. It is never sent anywhere. If you use a photo of your signature, shoot it on white paper and tick “Make white background transparent”.

⚠️ This is a picture placed on the document. It is not a digital signature issued by a certification provider. If an agency requires a digital signature, you need a dedicated service.

📝 PDF to Word

Convert a PDF to an editable Word (.docx) file that keeps paragraphs, font sizes, bold text and images.

  • Accepts: one PDF at a time
  • Gives you: filename.docx
  1. Choose “PDF to Word” and add the file
  2. Tap “Start processing”. Scanned pages take longer, several seconds per page
  3. Open the file in Word and proof-read it before real use

💡 For scanned or photographed PDFs, the tool uses OCR to read the Thai and English text on your device. The first time, it downloads the reader (about 10 MB, so you must be online once) and then keeps it on your device.

⚠️ OCR can misread text, especially small Thai characters and handwriting. It works on up to 20 pages per file. Complex tables and multi-column layouts may shift, and you will need to tidy them in Word.

📊 PDF to Excel

Pull the text of tables in a PDF out as a CSV file that opens in Excel or Google Sheets.

  • Accepts: a PDF with real text, one at a time
  • Gives you: filename_EasyConvert.csv
  1. Choose “PDF to Excel” and add the file
  2. Tap “Start processing”
  3. Open the .csv in Excel. Each line of text in the PDF becomes a row

⚠️ Scanned PDFs are not supported (this tool has no OCR). If you cannot drag-select text in the PDF, try PDF to Word first.

How to unlock Premium

  1. Tap “Upgrade to Pro” at the top right, or scroll to the plans on the home page
  2. Pick the 7-day, monthly or yearly plan. You are taken to the Stripe payment page
  3. Pay (scan the PromptPay QR) and come back to the site. It checks the payment and unlocks Premium by itself
  4. The top-right button changes to “👑 Premium (PRO)” and the home page shows how much time is left

💡 It is a one-time payment with no auto-renewal. The period counts from the payment date of your latest plan, so buy again when your access is close to ending.

Paid but still not unlocked?

Premium is stored in the browser you paid with. If you switch device, switch browser or clear site data, restore it like this:

  1. Tap “Upgrade to Pro”, then “Already paid but not unlocked?”
  2. Enter the email you paid with and the receipt number from Stripe’s email (under Receipt, it looks like 1757-4733)
  3. Tap “Restore access”. You get back the time you have left

On iPhone / iPad / Android

Open it in Safari or Chrome

If you open the link from inside an app such as LINE or Facebook, that in-app browser may not be able to pick or download files. Open the link in Safari or Chrome instead. The site shows a “Copy link” button when it detects this.

Finding your file on iPhone / iPad

  1. When processing is done, tap the blue “Save file” button
  2. Choose “Download” if a menu appears
  3. Open the Files app and go to the Downloads folder to find it

Works without internet

After the first visit your browser keeps a copy of the site, so the tools work even with Wi-Fi off (except payment, and the first download of the OCR reader).

Dark / light mode

Tap the 🌙 or ☀️ icon at the top right to switch. The site remembers your choice on this device.

Having trouble?

It says you’ve used all 2 free runs of this tool today

The free runs are counted per tool. Other tools still work. This one resets tomorrow, or you can choose a Premium plan to continue right away.

It says the file is over 15 MB

Free use works when the total size of the selected files is 15 MB or less, for every tool. For anything bigger, choose Premium for unlimited size, shrink or split the file with another program first, or try one file at a time.

It says the PDF is password-protected or damaged

The site cannot open a PDF locked with a password. Remove the password in your PDF reader and save a new copy first. For a damaged file, ask for the original again, or open and re-save it in the program that made it.

It says “File type doesn’t match the selected tool”

Each tool accepts different files. Check the line under the drop box, such as “PDF files” or “Image files”, and whether the tool takes “multiple files allowed” or “one file at a time”.

Processing finished but nothing was downloaded

Tap the blue “Save file” button that appears under the Start button. On iPhone and iPad choose “Download”, then find the file in the Files app. If it still does not work, open the site directly in Safari or Chrome (not from inside another app).

It is slow or seems stuck

Files with hundreds of pages or very high-resolution pictures use a lot of your device’s memory. Try splitting them (Extract pages) or closing other tabs. OCR in PDF to Word is slower than usual because it reads the text from pictures page by page.

PDF to Word does not look like the original

Word and PDF lay pages out differently, especially for complex tables, multi-column documents and fonts that are not installed on your device. Install the fonts the document uses, check any Thai text that OCR misread, and tidy the tables in Word.

Watermarking or compressing made the text unselectable

That is normal for the modes that turn pages into pictures (watermark, Medium and Strong compression, Shrink to size). To keep the text selectable, use Compress PDF at the Light level.
