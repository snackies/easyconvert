    วิธีใช้ “ลายน้ำสำเนา” 3 ขั้นตอน

    1. วางรูปหรือ PDF ของสำเนาในกรอบด้านบน (หลายไฟล์ได้)
    2. พิมพ์ข้อความลายน้ำ หรือเลือกข้อความสำเร็จรูปแล้วแก้ต่อ ปรับ “ความเข้ม” ให้อ่านชัดแต่ไม่บังข้อมูลสำคัญ
    3. กด “เริ่มประมวลผล” แล้วบันทึกไฟล์

    เหมาะกับงานแบบไหน

    • ส่งสำเนาบัตรประชาชนให้บริษัทหรือหน่วยงานโดยระบุว่าใช้เพื่ออะไร
    • ส่งสำเนาพาสปอร์ตหรือทะเบียนบ้านเพื่อสมัครบริการ
    • ใส่ข้อความระบุผู้รับกับเอกสารที่ส่งออกไปหลายที่

    คำถามที่พบบ่อยของ “ลายน้ำสำเนา”

    ข้อความลายน้ำควรเขียนอย่างไร

    ควรบอก 3 อย่าง คือ ใครคือผู้รับ ใช้เพื่ออะไร และห้ามใช้อย่างอื่น เช่น “สำเนาเพื่อสมัครงานบริษัท ABC เท่านั้น ห้ามใช้เพื่อการอื่น”

    ลายน้ำลบออกจากไฟล์ได้ไหม

    ไม่ได้ ผลลัพธ์เป็นภาพ ลายน้ำจึงลบออกจากไฟล์ไม่ได้ และถ้าเป็น PDF ข้อความในไฟล์จะเลือกไม่ได้ ควรเก็บไฟล์ต้นฉบับไว้ด้วย

    How to use “Copy watermark” in 3 steps

    1. Drop the images or PDFs of your copies into the box above (several files are fine).
    2. Type the watermark text or tap a preset and edit it. Adjust the opacity so it stays readable without hiding key details.
    3. Press “Start” and save the file.

    What it's good for

    • Send an ID card copy to a company or agency and say what it's for
    • Send passport or house registration copies for a service sign-up
    • Mark each copy with its recipient when you send documents to several places

    FAQ: “Copy watermark”

    What should the watermark say?

    Say three things: who the recipient is, what it is for, and that it must not be used for anything else. For example: “Copy for ABC Co. job application only. Not for any other use.”

    Can the watermark be removed?

    No. The result is an image, so the watermark can't be taken out of the file, and a PDF's text is no longer selectable. Keep your original file as well.

    Is my ID card file sent to a server?

    No. The watermark is added in your browser and the file is not uploaded. Be careful how you share the file afterwards.
