ไฟล์ของคุณไม่ได้ออกจากเครื่อง และคุณตรวจสอบเองได้

EasyConvert ออกแบบให้ทุกเครื่องมือทำงานในเบราว์เซอร์ของคุณ ไม่มีขั้นตอนอัปโหลดไฟล์ไปที่ไหน หน้านี้อธิบายว่าเราทำอย่างไร และคุณพิสูจน์ได้อย่างไรโดยไม่ต้องเชื่อคำพูดของเรา

สิ่งที่เราทำเพื่อไม่ให้ไฟล์หลุด

  • ประมวลผลในเบราว์เซอร์: การแปลง รวม แยก ลดขนาด และใส่ลายน้ำ ทำด้วยโค้ดที่รันบนเครื่องคุณ ไฟล์ไม่ถูกส่งเป็นคำขอไปยังเซิร์ฟเวอร์ของเรา
  • เบราว์เซอร์เป็นผู้บังคับ: เว็บส่งนโยบาย Content-Security-Policy ที่สั่งให้เบราว์เซอร์บล็อกการส่งข้อมูลออกไปยังเว็บอื่น (connect-src 'self') และไม่โหลดฟอนต์ รูป หรือสคริปต์จากบริษัทโฆษณา
  • เซิร์ฟเวอร์ของเรามี 3 ฟังก์ชัน และไม่มีฟังก์ชันไหนรับไฟล์: สร้างหน้าชำระเงิน (create-checkout) ยืนยันการชำระเงิน (claim) และตรวจสิทธิ์ (verify)
  • ไม่มีโฆษณา และไม่มีสคริปต์ติดตามของบริษัทอื่น: นโยบายความปลอดภัยของเว็บ (CSP) ไม่อนุญาตให้โหลดสคริปต์จากโดเมนอื่น สิ่งเดียวที่นับการเข้าชมคือ Vercel Web Analytics ซึ่งทำงานจากโดเมนของเราเอง ไม่ใช้คุกกี้ และไม่เกี่ยวกับไฟล์ของคุณ (ดูหัวข้อ “การนับสถิติการเข้าชม” ด้านล่าง ปิดได้เอง) หากวันหนึ่งเพิ่มโฆษณา เราจะแจ้งในหน้านี้ก่อน เพราะโฆษณาเปลี่ยนระดับความเป็นส่วนตัว
  • ใช้งานแบบออฟไลน์ได้: หลังเปิดเว็บครั้งแรก เบราว์เซอร์จะเก็บเว็บไว้ในเครื่อง คุณจึงใช้งานเครื่องมือโดยไม่มีอินเทอร์เน็ตได้
  • ข้อมูลการชำระเงินอยู่ที่ Stripe: เราไม่เห็นเลขบัตรหรือบัญชีธนาคารของคุณ เราเก็บเพียงรหัสการชำระเงินและอีเมลที่คุณกรอกกับ Stripe เพื่อยืนยันสิทธิ์

ตรวจสอบเองใน 3 นาที

วิธีที่ 1: ทดสอบโหมดเครื่องบิน (ง่ายที่สุด)

  1. เปิดหน้าเครื่องมือ แล้วลองใช้เครื่องมือที่เกี่ยวกับ PDF หนึ่งครั้ง (เพื่อให้ตัวประมวลผล PDF โหลดเสร็จ)
  2. เปิดโหมดเครื่องบิน หรือปิด Wi-Fi และข้อมูลมือถือ
  3. เลือกไฟล์แล้วกดประมวลผล ถ้าไฟล์ถูกแปลงและดาวน์โหลดได้ แสดงว่าการประมวลผลไม่ต้องใช้อินเทอร์เน็ต ไฟล์จึงไม่ได้ถูกส่งไปไหน

วิธีที่ 2: ดูแท็บ Network (คอมพิวเตอร์)

  1. กด F12 แล้วเปิดแท็บ Network
  2. เลือกไฟล์และกดประมวลผล
  3. ดูรายการคำขอ จะไม่มีคำขอ POST ที่มีไฟล์แนบ คำขอที่เห็นมีเพียงการโหลดไลบรารี และ /api/ ของระบบชำระเงินเมื่อคุณกดซื้อแพ็กเกจ กับคำขอนับการเข้าชมหน้าเว็บ (/_vercel/insights/) ที่ส่งเพียงที่อยู่หน้าเว็บ ไม่มีไฟล์แนบ

วิธีที่ 3: ดูตัวนับบนหน้าเว็บ

หลังประมวลผลเสร็จ หน้าเว็บแสดง "ใบรับรองการประมวลผล" ที่นับคำขอส่งข้อมูล (fetch, XHR, beacon) ที่เบราว์เซอร์บันทึกระหว่างประมวลผล ตัวเลขที่ถูกต้องคือ 0 ตัวนับนี้อ่านจากบันทึกของเบราว์เซอร์เอง ไม่ใช่ตัวเลขที่โค้ดของเราเขียนขึ้น แต่ใช้เป็นสัญญาณประกอบ หลักประกันจริงคือข้อ 1-2 หมายเหตุ: ตัวนับนี้ไม่รวมคำขอนับการเข้าชมหน้าเว็บ (/_vercel/insights/) เพราะส่งตอนเปิดหน้าเว็บเท่านั้น ไม่ได้ส่งตอนประมวลผล และไม่มีข้อมูลจากไฟล์ของคุณ

การนับสถิติการเข้าชม

เราใช้ Vercel Web Analytics (Vercel คือผู้ให้บริการที่โฮสต์เว็บนี้) นับจำนวนผู้เข้าชม เพื่อรู้ว่าหน้าไหนมีคนใช้และปรับปรุงเว็บให้ตรงความต้องการ สคริปต์โหลดจากโดเมนของเราเอง ไม่ใช่โดเมนอื่น รายละเอียดข้อมูลที่ Vercel เก็บอ้างอิงจาก เอกสารความเป็นส่วนตัวของ Vercel

  • ข้อมูลต่อการเข้าชมหนึ่งครั้ง: เวลา ที่อยู่หน้าเว็บ (URL) เว็บที่พามา (referrer) ประเทศหรือพื้นที่โดยประมาณ ระบบปฏิบัติการ เบราว์เซอร์ และประเภทอุปกรณ์ (มือถือ/แท็บเล็ต/คอมพิวเตอร์)
  • ไม่ใช้คุกกี้: Vercel ระบุว่าแยกผู้เข้าชมด้วยค่าแฮชจากคำขอ และทิ้งข้อมูลช่วงเข้าชมภายใน 24 ชั่วโมง ไม่ได้ติดตามคุณข้ามเว็บอื่น
  • ไม่เกี่ยวกับไฟล์ของคุณ: ไม่มีชื่อไฟล์ เนื้อหาไฟล์ หรือสิ่งที่คุณพิมพ์ในเครื่องมือถูกส่งไปนับสถิติ และไม่ส่งอะไรเพิ่มตอนคุณกดประมวลผล
  • เคารพการตั้งค่าของคุณ: ถ้าเบราว์เซอร์ส่งสัญญาณ Do Not Track หรือ Global Privacy Control ตัวนับจะไม่โหลดเลย และคุณปิดเองได้ด้วยปุ่มด้านล่าง (จำไว้ในเบราว์เซอร์นี้เท่านั้น)

ถ้าคุณใช้ตัวบล็อกโฆษณา ตัวนับอาจถูกบล็อก ซึ่งไม่กระทบการใช้งานเครื่องมือใด ๆ

ข้อจำกัดที่เราบอกตรง ๆ

  • เราป้องกันไม่ให้ไฟล์ออกจากเว็บของเรา แต่ป้องกันมัลแวร์ ส่วนขยายเบราว์เซอร์ที่ไม่น่าไว้ใจ หรือคนที่ใช้เครื่องร่วมกับคุณไม่ได้
  • ไฟล์ที่ได้จะถูกบันทึกในโฟลเดอร์ดาวน์โหลดของเครื่องคุณ ควรลบเมื่อใช้เสร็จ โดยเฉพาะเครื่องที่ใช้ร่วมกัน
  • ไลบรารีประมวลผล PDF และฟอนต์ถูกเก็บไว้ในเว็บของเราเอง ไม่ได้โหลดจาก CDN หรือบริษัทภายนอก (ตรวจได้ในแท็บ Network ว่ามีคำขอไปที่โดเมนอื่นหรือไม่)
  • การอ่านตัวหนังสือจากภาพ (OCR) ในเครื่องมือ PDF เป็น Word ใช้ Tesseract ที่เก็บไว้ในเว็บของเราเองและทำงานในเครื่องคุณ ภาพของหน้าเอกสารไม่ถูกส่งออก ไฟล์ของตัวอ่านประมาณ 10 MB จะถูกโหลดจากเว็บของเราเมื่อใช้ครั้งแรกเท่านั้น
  • ตัวนับโควตาทดลองใช้ (2 ครั้งต่อเครื่องมือต่อวัน) เก็บอยู่ในเบราว์เซอร์ของคุณเอง ไม่ได้เก็บบนเซิร์ฟเวอร์ ผู้ใช้ที่ล้างข้อมูลเบราว์เซอร์จะได้โควตาใหม่ ซึ่งเรายอมรับได้
  • หน้านี้เป็นคำอธิบายทางเทคนิค ไม่ใช่คำปรึกษากฎหมาย

สิ่งที่ยังไม่สามารถรับประกันได้

เราพิสูจน์ได้ว่า "เว็บของเราไม่ส่งไฟล์ออกไป" แต่พิสูจน์แทนเครื่องของคุณไม่ได้ หากเครื่องมีมัลแวร์หรือส่วนขยายเบราว์เซอร์ที่แอบอ่านหน้าจอ ข้อมูลอาจรั่วจากจุดนั้นได้ ควรใช้เครื่องที่ไว้ใจได้กับเอกสารสำคัญ และเมื่อเราแก้ไขโค้ดในอนาคต ผู้ใช้ตรวจซ้ำได้ด้วยวิธีด้านบนเสมอ
