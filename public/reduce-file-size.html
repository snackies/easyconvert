    How to use “Shrink to size” in 3 steps

    1. Drop images or PDFs into the box above (several files are fine).
    2. Type the maximum size you need and choose KB or MB.
    3. Press “Start”, check the original and new sizes, then save.

    What it's good for

    • Fit photos and documents into a job site with a size limit
    • Submit online forms that cap files at 1 or 2 MB
    • Shrink several ID or document files at once

    FAQ: “Shrink to size”

    A job site limits file size. What do I do?

    Set the maximum to the site's limit, for example 200 KB, and press Start. Quality is lowered step by step until the file fits.

    What if the file is already smaller than my limit?

    It is returned unchanged, so quality is not reduced for no reason.

    Can I still select text in a shrunk PDF?

    No. A shrunk PDF becomes images. If it can't reach your limit even at the smallest setting, you'll be asked to try a larger target.
